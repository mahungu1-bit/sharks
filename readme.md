

# 🦈 Shark World

Welcome to Shark World! 🌊

## 📖 About the Project

Shark World is a website created using HTML and CSS to explore the amazing world of sharks. It provides information about different shark species and their importance in the ocean.

## ✨ Features

- 🦈 Beautiful shark pictures
- 🌊 Ocean-themed background
- 📚 Information about sharks
- 🐋 Great White Shark facts
- 🦈 Whale Shark facts
- ⚡ Hammerhead Shark facts
- 💙 Blue glowing hover effects
- 📱 Responsive design
- 🧭 Navigation bar

## 💻 Technologies Used

- HTML5
- CSS3

## 📂 Project Files

- `index.html` - Contains the website structure.
- `style.css` - Contains the website styling.
- `README.md` - Contains information about the project.

## 🚀 How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in your browser.
4. Enjoy exploring Shark World!

## 🎯 Purpose

This project was created to practice HTML and CSS and learn how to build a beautiful website.
